# My first program (age 13)

One of the first programs I ever wrote, to automate my physics lab homework. It takes a set of repeated measurements and computes:

- mean
- deviations and squared deviations
- standard deviation (σ)
- uncertainty from the half-range ("semidispersione massima") and how it compares with σ
- relative and percentage uncertainty for both methods

It is kept here unchanged, as a snapshot of where I started. The repetition (`dato1`…`dato8`, `scarto1`…`scarto8`) comes from a time before I knew about loops over lists.

```bash
python "primo programma (13 anni).py"
```
